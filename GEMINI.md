# AI Agent Entry Point

Before doing any repository work, read and follow `AGENTS.md`, then read `.codex/README.md` and load the task-relevant `.codex/skills/*/SKILL.md` files.

For debugging, investigation, bug fixing, or code changes, `.codex/skills/evidence-first-investigation/SKILL.md` is mandatory unless a higher-priority instruction explicitly says otherwise.

Do not begin with a repository-wide scan. Do not bypass the repository skill bootstrap because the task appears simple.
