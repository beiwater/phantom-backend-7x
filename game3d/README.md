# 体素纪元(Voxel Era)

Three.js 体素风格的「经营 + 文明时代 + RTS 战争」小游戏,独立于 SimCompanies 后端,无构建步骤。

```bash
node game3d/serve.mjs          # → http://127.0.0.1:3200/
node --test game3d/tests/*.test.mjs   # 经济/地图/命令/回放无头测试
node game3d/tests/dom.e2e.mjs         # DOM 回归(需 playwright-core)
```

- `?new=1` 强制新局(忽略本地存档),`?seed=N` 换地图种子,`?diff=easy|normal|hard` 难度。
- **本机合作**:同一浏览器开两个标签页 `?new=1&coop=p1` 与 `?new=1&coop=p2`,两人锁步共同指挥同一文明(共享经济与部队)。
- `gallery.html` 展示全部体素模型(28 种建筑 × 各等级、道路/城墙拼接、单位、道具)。

## 玩法

| 系统 | 说明 |
| --- | --- |
| 地块扩建 | 64×64 格地图划分为 8×8 地块,起始拥有 4 块;「扩地」购买相邻地块,价格 ×1.55 递增 |
| 道路拼接 | 拖拽铺路,自动拼接直线/转角/T 字/十字;生产建筑须邻接**连通指挥中心**的道路,卡车沿路运货 |
| 模块化建筑 | 每升一级增加一个可见模块(楼层/烟囱/储罐/温室…),速度 +60%;指挥中心外观随时代变化 |
| 产业链 | 原料(谷物/原木/石料/铁矿/煤/原油/水)→ 加工(食物/木板/钢材/水泥/燃油/塑料/弹药/零件/电子)→ 建造与军工 |
| 文明时代 | 科技树 20 项,拓荒 → 工业 → 现代,解锁建筑与兵种,含全局加成 |
| RTS 战争 | 6 种兵种(含侦察兵),框选/编队/攻击移动,A* 寻路,防御塔与城墙;东北敌军要塞定期渡河进攻,摧毁敌军指挥中心获胜 |

## 深度系统

- **市场**:每种货物价格随抛售下跌、随时间回升,并有需求波动与商队事件
- **相邻协同**:上下游建筑紧贴放置 +10%/种(最多 +30%),放置预览即时提示
- **民心**:口粮、服务、教育加分,重工业污染与敌军压境扣分;影响税收与生产,过低会罢工
- **随机事件**:丰收、商队、富矿、移民潮、火灾、科学突破、节庆
- **政策**:12 项,时代解锁槽位,替换收费并有冷却
- **贸易合同**:城邦限时高价订单,交付提升声望,过期扣声望
- **古代遗迹**:探索获得宝藏、典籍、物资、雇佣兵或地图
- **战争迷雾**:未探索/已探索/视野内三态,只属于本地视图
- **老兵军衔**:击杀晋升,星标显示,伤害加成
- **敌军 AI**:定时波次随时代升级;第 8 分钟起向玩家方向扩张前哨领土(拔除后地块回归中立);要塞内有可劫掠的经济建筑(摧毁可使波次缩减至多 40%);要塞内被毁建筑会重建;指挥中心随时代升级;可进贡推迟进攻
- **国家工程**:大粮仓/大运河/国家铁路网/太空计划,分批投入材料,完工永久加成(太空计划=科技胜利)
- **伟人**:科学家/商人/将军/工程师,按累计成就诞生,择机使用
- **军队补给**:步兵耗食物、载具耗燃油,补给不足伤害 -30%
- **天气**:晴/雨/雷暴/干旱/大雾,影响农业、民心与视野
- **桥梁**:研究「工程学」后可在水面铺路,开辟新的渡河通道(敌军也能走)
- **自动铺路**:放置未连通建筑时自动铺最短路;**专精模块**:3 级建筑可装效率/环保/仓储模块
- **三种胜利**:征服 / 科技 / 经济;难度三档;**三种地图**:大河 / 湖泽 / 高地(山脊与山口)
- **兵种**:克制表(步兵/载具/空中/建筑)、老兵军衔、战地休整、民兵半价换装步枪兵;敌军波次随机走北/中/南三路并提前预警
- **研究队列**(最多 4 项)、**集市保留量**可调、**规划视图**(污染/物流,U)、选中建筑显示协同伙伴与污染范围
- **昼夜循环**(夜间灯火)、天气粒子、合成音效、画质自动降档、统计面板(含发展曲线)、百科、问题提醒、可点击定位的警报(Z)
- **标题界面 / 成就 20 项 / 文明评分与本机排行榜 / 存档导入导出 / 录像回放(读档后也逐位一致)**
- **难度**:和平沙盒 / 和平建设 / 标准 / 铁血;**触屏**:双指平移缩放、轻点下令;手机竖屏布局

## 多人预留

命令总线 + 20 Hz 固定步长 + 种子随机数 + 状态校验和;已实现锁步传输(合作模式,本机多标签页可玩)与录像回放。接入网络只需提供 `{ post, onMessage }` 通道。详见 [docs/multiplayer.md](docs/multiplayer.md)。

核心:指挥中心 · 采集:农场、伐木场、采石场、水泵站、铁矿场、煤矿、油井 · 加工:食品厂、锯木厂、炼钢厂、水泥厂、火力电厂、炼油厂、化工厂、军火厂、机械厂、电子厂 · 民生:民居、集市、仓库 · 科研:学院、研究所 · 军事:兵营、战车工厂、直升机场 · 防御:防御塔、城墙

## 代码结构

```
src/data/      静态数据:资源、建筑、科技、兵种、任务
src/engine/    体素构建器(面剔除 + AO)、渲染舞台、RTS 镜头
src/world/     地图生成、地形渲染、建筑/道路/卡车视图
src/net/       命令总线与传输层(本地/回放,锁步接口)
src/sim/       状态与校验、固定步长循环、经济/市场/民心/合同/遗迹/胜利
src/models/    28 种建筑与单位/道具的体素模型
src/rts/       单位、寻路、战斗、敌军 AI、选择与命令、特效
src/ui/        HUD、工具栏、信息面板、科技树、任务、小地图、浮动标签、输入
```
